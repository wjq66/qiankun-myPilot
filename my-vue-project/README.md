# 🔐 用户认证系统

一个完整的 Vue 3 + Vite + Router + Pinia 用户认证系统，包含登录、注册和忘记密码功能。

## ✨ 功能特性

- 🔑 **用户登录** - 用户名和密码登录
- 📝 **用户注册** - 完整的注册流程，包含密码强度检测
- 🔒 **忘记密码** - 通过用户名和邮箱重置密码
- 🏠 **主页面** - 登录后的用户仪表板
- 🛡️ **路由守卫** - 自动保护需要认证的页面
- 💾 **状态管理** - 使用 Pinia 管理用户状态
- 📱 **响应式设计** - 支持移动端和桌面端

## 🚀 快速开始

### 1. 安装依赖
```bash
npm install
```

### 2. 启动开发服务器
```bash
npm run dev
```

### 3. 访问应用
打开浏览器访问 `http://localhost:5173`

## 📁 项目结构

```
src/
├── stores/
│   └── auth.ts              # 用户认证状态管理
├── views/
│   ├── HomeView.vue         # 主页面（需要登录）
│   ├── LoginView.vue        # 登录页面
│   ├── RegisterView.vue     # 注册页面
│   └── ForgotPasswordView.vue # 忘记密码页面
├── router/
│   └── index.ts             # 路由配置
├── App.vue                  # 根组件
└── main.ts                  # 应用入口
```

## 🔧 技术栈

- **Vue 3** - 渐进式 JavaScript 框架
- **Vite** - 快速构建工具
- **Vue Router** - 官方路由管理器
- **Pinia** - Vue 状态管理库
- **TypeScript** - 类型安全的 JavaScript
- **CSS3** - 现代化样式设计

## 📋 页面说明

### 登录页面 (`/login`)
- 用户名和密码输入
- 密码显示/隐藏切换
- 表单验证
- 忘记密码链接

### 注册页面 (`/register`)
- 用户名、邮箱、密码输入
- 密码强度检测
- 密码确认验证
- 实时表单验证

### 忘记密码页面 (`/forgot-password`)
- 用户名和邮箱输入
- 表单验证
- 操作说明

### 主页面 (`/`)
- 用户信息展示
- 功能导航卡片
- 快速操作按钮
- 系统信息显示

## 🛡️ 安全特性

- **路由守卫** - 自动重定向未认证用户
- **表单验证** - 客户端输入验证
- **密码强度** - 实时密码强度检测
- **状态持久化** - 使用 localStorage 保存登录状态

## 🎨 UI/UX 特性

- **现代化设计** - 渐变背景和卡片式布局
