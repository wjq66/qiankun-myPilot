## 技术选型与原因

### 2.1 为什么选择分片上传？

#### 问题：大文件直接上传的痛点
```
❌ 问题1: 网络超时
   - 大文件上传时间长，容易超时
   - 失败后需要重新上传整个文件

❌ 问题2: 内存占用
   - 浏览器需要将整个文件加载到内存
   - 可能导致浏览器崩溃

❌ 问题3: 无法断点续传
   - 网络中断后，已上传部分丢失
   - 用户体验差
```

#### 解决方案：分片上传
```
✅ 优势1: 网络容错
   - 单个分片失败，只需重传该分片
   - 其他分片不受影响

✅ 优势2: 内存友好
   - 每次只处理一个分片（2MB）
   - 内存占用固定且小

✅ 优势3: 支持断点续传
   - 记录已上传分片
   - 只上传未完成的分片
```

### 2.2 为什么使用 Web Worker？

#### 问题：主线程阻塞
```javascript
// ❌ 主线程执行大文件处理
const file = event.target.files[0]
const chunks = createChunks(file)  // 阻塞主线程
const hash = calculateHash(file)    // 阻塞主线程
// 结果：页面卡顿，用户体验差
```

#### 解决方案：Web Worker
```javascript
// ✅ 后台线程处理
const worker = new Worker('chunkWorker.ts')
worker.postMessage({ type: 'chunk', file })
// 主线程不阻塞，页面流畅
```

**选型原因：**
- ✅ 避免主线程阻塞，保持 UI 响应
- ✅ 利用多核 CPU，提升处理速度
- ✅ 独立线程，不影响页面性能

### 2.3 为什么使用 IndexedDB？

#### 对比其他存储方案

| 存储方案 | 容量限制 | 持久化 | 性能 | 适用场景 |
|---------|---------|--------|------|---------|
| **localStorage** | 5-10MB | ✅ | 快 | 小数据 |
| **sessionStorage** | 5-10MB | ❌ | 快 | 会话数据 |
| **IndexedDB** | 几GB | ✅ | 中等 | **大文件** |
| **内存** | 无限制 | ❌ | 最快 | 临时数据 |

**选型原因：**
- ✅ 容量大（几GB），适合存储分片
- ✅ 持久化存储，支持断点续传
- ✅ 支持二进制数据（Blob）
- ✅ 异步操作，不阻塞主线程

### 2.4 为什么使用 WebSocket？

#### 对比轮询方案

| 方案 | 实时性 | 服务器压力 | 网络开销 | 复杂度 |
|-----|--------|-----------|---------|--------|
| **HTTP 轮询** | 低 | 高 | 高 | 低 |
| **WebSocket** | ✅ 高 | ✅ 低 | ✅ 低 | 中等 |

**选型原因：**
- ✅ 实时双向通信，服务器可主动推送
- ✅ 减少网络请求，降低服务器压力
- ✅ 支持断线重连，提高可靠性

### 2.5 为什么后端合并而不是前端合并？

#### 方案对比

| 特性 | 前端合并 | 后端合并（当前方案） |
|------|---------|---------------------|
| **内存占用** | ❌ 高（需要所有分片） | ✅ 低（只保存单个分片） |
| **断点续传** | ❌ 困难 | ✅ 容易 |
| **并发效率** | ❌ 低 | ✅ 高 |
| **网络容错** | ❌ 差 | ✅ 好 |
| **适用场景** | 小文件 | ✅ **大文件** |

**选型原因：**
- ✅ 内存占用低，适合大文件
- ✅ 支持断点续传
- ✅ 服务器处理能力强，可以使用流式处理

### 3.1 文件切片（Chunking）

#### 实现思路

```typescript
/**
 * 文件切片的核心步骤
 */
async function createChunks(file: File, chunkSize: number) {
  const chunks: ChunkInfo[] = []
  const totalChunks = Math.ceil(file.size / chunkSize)
  
  for (let i = 0; i < totalChunks; i++) {
    const start = i * chunkSize
    const end = Math.min(start + chunkSize, file.size)
    const blob = file.slice(start, end)  // 关键：使用 File.slice()
    
    chunks.push({
      index: i,
      start,
      end,
      blob
    })
  }
  
  return chunks
}
```

#### 关键技术点

1. **File.slice()** - 零拷贝切片
   ```typescript
   // File.slice() 不会复制数据，只是创建引用
   const blob = file.slice(start, end)  // 性能高，内存占用低
   ```

2. **Web Worker 处理** - 避免主线程阻塞
   ```typescript
   // 在 Worker 中切片，不阻塞主线程
   const worker = new Worker('chunkWorker.ts')
   worker.postMessage({ type: 'chunk', file, chunkSize })
   ```

3. **进度回调** - 提升用户体验
   ```typescript
   // 定期发送进度更新
   if (i % 10 === 0) {
     onProgress((i / totalChunks) * 100)
   }
   ```

### 3.2 Hash 计算

#### 为什么需要 Hash？

1. **文件唯一标识**
   - 相同文件生成相同 Hash
   - 用于断点续传和去重

2. **分片校验**
   - 验证分片完整性
   - 检测传输错误

#### 实现思路

```typescript
/**
 * 文件 Hash 计算（分片方式，避免内存溢出）
 */
async function calculateFileHash(file: File, chunkSize: number) {
  const spark = new SparkMD5.ArrayBuffer()
  const totalChunks = Math.ceil(file.size / chunkSize)
  
  // 分片计算，避免一次性加载整个文件
  for (let i = 0; i < totalChunks; i++) {
    const start = i * chunkSize
    const end = Math.min(start + chunkSize, file.size)
    const blob = file.slice(start, end)
    
    // 将 Blob 转换为 ArrayBuffer
    const arrayBuffer = await blob.arrayBuffer()
    
    // 追加到 Hash 计算器
    spark.append(arrayBuffer)
  }
  
  // 完成计算
  return spark.end()
}
```

#### 关键技术点

1. **分片计算** - 避免内存溢出
   ```typescript
   // ❌ 错误：一次性计算整个文件
   const arrayBuffer = await file.arrayBuffer()  // 大文件会内存溢出
   
   // ✅ 正确：分片计算
   for (let chunk of chunks) {
     spark.append(chunk.arrayBuffer())
   }
   ```

2. **FileReader vs arrayBuffer()**
   ```typescript
   // 方式1: FileReader（异步，不阻塞）
   const reader = new FileReader()
   reader.onload = (e) => {
     spark.append(e.target.result as ArrayBuffer)
   }
   reader.readAsArrayBuffer(blob)
   
   // 方式2: arrayBuffer()（同步，可能阻塞）
   const arrayBuffer = await blob.arrayBuffer()
   spark.append(arrayBuffer)
   ```

### 3.3 断点续传

#### 实现思路

```typescript
/**
 * 断点续传的核心流程
 */
async function resumeUpload(file: UploadFile) {
  // 1. 计算文件 Hash（用于标识文件）
  const fileHash = await calculateFileHash(file.file)
  
  // 2. 检查 IndexedDB 是否有已保存的数据
  const metadata = await indexedDBManager.getFileMetadataByHash(fileHash)
  
  if (metadata) {
    // 3. 恢复已上传的分片信息
    const uploadedChunks = metadata.uploadedChunks  // [0, 1, 2, ...]
    const savedChunks = await indexedDBManager.getAllChunks(file.id)
    
    // 4. 只上传未完成的分片
    const pendingChunks = chunks.filter(
      (_, index) => !uploadedChunks.includes(index)
    )
    
    // 5. 继续上传
    await uploadChunks(pendingChunks)
  } else {
    // 首次上传
    await uploadChunks(allChunks)
  }
}
```

#### 关键技术点

1. **文件 Hash 作为唯一标识**
   ```typescript
   // 相同文件生成相同 Hash
   const fileHash = await calculateFileHash(file)
   // 用于查找已保存的上传记录
   ```

2. **IndexedDB 存储结构**

     fileHash: 'abc123...',

### 3.4 并发控制

#### 实现思路

```typescript
/**
 * 请求队列 - 控制并发数量
 */
class RequestQueue {
  private queue: Task[] = []
  private running: number = 0
  private maxConcurrent: number = 3
  
  async add(task: Task) {
    return new Promise((resolve, reject) => {
      this.queue.push({
        ...task,
        resolve,
        reject
      })
      this.process()
    })
  }
  
  private async process() {
    // 如果已达到最大并发数，等待
    if (this.running >= this.maxConcurrent) {
      return
    }
    
    // 从队列中取出任务
    const task = this.queue.shift()
    if (!task) return
    
    this.running++
    
    try {
      const result = await task.execute()
      task.resolve(result)
    } catch (error) {
      task.reject(error)
    } finally {
      this.running--
      this.process()  // 处理下一个任务
    }
  }
}
```

#### 关键技术点

1. **队列管理**
   ```typescript
   // 使用队列控制并发，而不是 Promise.all()
   // ❌ 错误：所有请求同时发送
   await Promise.all(chunks.map(chunk => uploadChunk(chunk)))
   
   // ✅ 正确：通过队列控制并发
   chunks.forEach(chunk => {
     requestQueue.add({
       execute: () => uploadChunk(chunk)
     })
   })
   ```

2. **优先级支持**
   ```typescript
   // 支持优先级队列
   queue.add({ priority: 1, execute: ... })  // 高优先级
   queue.add({ priority: 0, execute: ... })  // 低优先级
   ```

3. **自动重试**
   ```typescript
   // 失败自动重试
   try {
     await uploadChunk(chunk)
   } catch (error) {
     if (retryCount < maxRetries) {
       await retry()
     }
   }
   ```

### 4.2 分片上传实现

```typescript
/**
 * 上传单个分片
 */
private async uploadChunk(chunk: ChunkInfo): Promise<void> {
  // 1. 从 IndexedDB 获取分片（如果存在）
  let blob = chunk.blob
  const savedBlob = await indexedDBManager.getChunk(this.file.id, chunk.index)
  if (savedBlob) {
    blob = savedBlob
  }
  
  // 2. 创建 FormData
  const formData = new FormData()
  formData.append('file', blob)
  formData.append('chunkIndex', chunk.index.toString())
  formData.append('fileHash', this.fileHash)
  formData.append('fileName', this.file.name)
  formData.append('fileId', this.file.id)
  if (chunk.hash) {
    formData.append('chunkHash', chunk.hash)
  }
  
  // 3. 发送请求（支持取消）
  const abortController = new AbortController()
  this.uploadingRequests.set(chunk.index, abortController)
  
  const response = await fetch(this.options.uploadUrl!, {
    method: 'POST',
    body: formData,
    signal: abortController.signal  // 支持取消
  })
  
  // 4. 标记分片已上传
  this.uploadedChunkIndices.add(chunk.index)
  this.updateProgress()
  this.updateMetadata()
}
```

### 4.3 Web Worker 切片实现

```typescript
/**
 * Web Worker 中处理文件切片
 */
self.onmessage = async function(e: MessageEvent<WorkerMessage>) {
  const { type, data } = e.data
  
  switch (type) {
    case 'chunk':
      await handleChunk(data as ChunkMessage)
      break
    case 'hash':
      await handleHash(data as HashMessage)
      break
    case 'fileHash':
      await handleFileHash(data as FileHashMessage)
      break
  }
}

/**
 * 处理文件切片
 */
async function handleChunk(message: ChunkMessage) {
  const { file, chunkSize, startIndex, endIndex } = message
  const chunks: ChunkInfo[] = []
  
  for (let i = startIndex; i < endIndex; i++) {
    const start = i * chunkSize
    const end = Math.min(start + chunkSize, file.size)
    const blob = file.slice(start, end)  // 切片
    
    chunks.push({
      index: i,
      start,
      end,
      blob
    })
    
    // 定期发送进度
    if ((i - startIndex) % 10 === 0) {
      self.postMessage({
        type: 'chunkProgress',
        data: {
          progress: ((i - startIndex + 1) / (endIndex - startIndex)) * 100,
          chunkIndex: i
        }
      })
    }
  }
  
  // 发送结果
  self.postMessage({
    type: 'chunkResult',
    data: { chunks }
  })
}
```

### 4.4 IndexedDB 存储实现

```typescript
/**
 * IndexedDB 管理器
 */
class IndexedDBManager {
  private db: IDBDatabase | null = null
  
  async init(): Promise<void> {
    return new Promise((resolve, reject) => {
      const request = indexedDB.open(DB_NAME, DB_VERSION)
      
      request.onupgradeneeded = (event) => {
        const db = (event.target as IDBOpenDBRequest).result
        
        // 创建分片存储
        if (!db.objectStoreNames.contains(STORE_CHUNKS)) {
          const chunkStore = db.createObjectStore(STORE_CHUNKS, { keyPath: 'id' })
          chunkStore.createIndex('fileId', 'fileId', { unique: false })
          chunkStore.createIndex('chunkIndex', 'chunkIndex', { unique: false })
        }
        
        // 创建文件元数据存储
        if (!db.objectStoreNames.contains(STORE_FILES)) {
          const fileStore = db.createObjectStore(STORE_FILES, { keyPath: 'fileId' })
          fileStore.createIndex('fileHash', 'fileHash', { unique: false })
        }
      }
      
      request.onsuccess = () => {
        this.db = request.result
        resolve()
      }
      
      request.onerror = () => {
        reject(new Error('Failed to open IndexedDB'))
      }
    })
  }
  
  /**
   * 保存分片
   */
  async saveChunk(fileId: string, chunkIndex: number, blob: Blob, hash?: string): Promise<void> {
    const transaction = this.db!.transaction([STORE_CHUNKS], 'readwrite')
    const store = transaction.objectStore(STORE_CHUNKS)
    
    await store.put({
      id: `${fileId}_${chunkIndex}`,
      fileId,
      chunkIndex,
      blob,
      hash
    })
  }
  
  /**
   * 获取分片
   */
  async getChunk(fileId: string, chunkIndex: number): Promise<Blob | null> {
    const transaction = this.db!.transaction([STORE_CHUNKS], 'readonly')
    const store = transaction.objectStore(STORE_CHUNKS)
    const request = store.get(`${fileId}_${chunkIndex}`)
    
    return new Promise((resolve) => {
      request.onsuccess = () => {
        resolve(request.result?.blob || null)
      }
      request.onerror = () => {
        resolve(null)
      }
    })
  }
}
```

        method: 'POST',
        body: formData,
        signal: abortController.signal
      })
      
      if (!response.ok) {

      }
      
      // 成功，退出重试循环
      return
      
    } catch (error) {
      retryCount++

        // 达到最大重试次数，抛出错误
        throw new Error(`上传失败，已重试 ${maxRetries} 次`)
      }

    }
  }
}
