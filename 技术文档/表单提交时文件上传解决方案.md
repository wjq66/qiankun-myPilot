# 表单提交时文件上传解决方案

## 📋 问题场景

在表单中，用户选择了大文件并开始上传，但文件还没完全上传完成时，用户想提交表单。

**需求：**
- ✅ 文件选择后立即开始上传（后台）
- ✅ 表单提交时，文件可以还在上传中
- ✅ 表单数据先提交，文件上传完成后自动关联

---

## 🎯 三种解决方案

### 方案1：预上传方案（推荐）⭐⭐⭐⭐⭐

**核心思路：**
- 文件选择后立即开始上传
- 上传完成后获得文件ID
- 表单提交时，已完成的文件使用文件ID，未完成的文件使用临时ID

**优点：**
- ✅ 用户体验好，文件提前上传
- ✅ 表单提交快，不需要等待
- ✅ 实现简单，逻辑清晰

**缺点：**
- ⚠️ 如果用户取消表单，已上传的文件需要清理

**流程图：**
```
用户选择文件
    ↓
立即开始上传（后台）
    ↓
用户填写表单
    ↓
用户点击提交
    ↓
检查文件状态
    ├── 已完成 → 使用文件ID
    └── 未完成 → 使用临时ID + Hash
    ↓
提交表单数据
    ↓
文件继续上传（后台）
    ↓
上传完成后关联到表单
```

---

### 方案2：异步提交方案 ⭐⭐⭐⭐

**核心思路：**
- 表单提交时先提交表单数据（包含临时ID）
- 文件继续在后台上传
- 上传完成后，调用接口关联文件到表单

**优点：**
- ✅ 表单提交快
- ✅ 文件上传和表单提交解耦

**缺点：**
- ⚠️ 需要服务器端支持文件关联
- ⚠️ 如果文件上传失败，需要处理

**流程图：**
```
用户选择文件
    ↓
开始上传（后台）
    ↓
用户填写表单
    ↓
用户点击提交
    ↓
提交表单数据（包含临时ID）
    ↓
返回表单ID
    ↓
文件继续上传（后台）
    ↓
上传完成后调用关联接口
    ↓
POST /api/form/associate-file
{
  formId: "form_123",
  tempId: "temp_456",
  fileId: "file_789"
}
```

---

### 方案3：等待完成方案（保守）⭐⭐⭐

**核心思路：**
- 表单提交时，等待所有文件上传完成
- 所有文件上传完成后，再提交表单

**优点：**
- ✅ 数据一致性好
- ✅ 实现简单

**缺点：**
- ❌ 用户体验差，需要等待
- ❌ 大文件上传时间长，用户等待时间长

**流程图：**
```
用户选择文件
    ↓
开始上传
    ↓
用户填写表单
    ↓
用户点击提交
    ↓
等待所有文件上传完成
    ↓
所有文件上传完成
    ↓
提交表单数据（包含文件ID）
```

## 💻 代码实现

### 1. 使用 useFormUpload Composable

```vue
<template>
  <form @submit.prevent="handleSubmit">
    <!-- 文件上传组件 -->
    <FileUpload
      v-model="formData.files"
      @file-added="handleFileAdded"
    />
    
    <!-- 其他表单字段 -->
    <input v-model="formData.title" placeholder="标题" />
    <textarea v-model="formData.description" placeholder="描述" />
    
    <!-- 提交按钮 -->
    <button type="submit" :disabled="isSubmitting">
      {{ isSubmitting ? '提交中...' : '提交' }}
    </button>
    
    <!-- 显示文件上传状态 -->
    <div v-if="hasPendingFiles">
      <p>文件上传中，您可以先提交表单...</p>
      <div v-for="status in fileStatuses" :key="status.tempId">
        {{ status.status === 'uploading' ? '上传中' : '等待中' }}: {{ status.progress }}%
      </div>
    </div>
  </form>
</template>

<script setup lang="ts">
import { ref, computed } from 'vue'
import { useFileList } from './composables/useFileList'
import { useFormUpload } from './composables/useFormUpload'

// 文件列表
const { fileList, addFile } = useFileList()

// 表单数据
const formData = ref({
  title: '',
  description: '',
  files: []
})

// 表单提交状态
const isSubmitting = ref(false)

// 文件上传管理（使用方案1：预上传）
const {
  startFileUpload,
  submitFormWithPreUploadedFiles,
  hasPendingFiles,
  getAllFileStatuses
} = useFormUpload(fileList, {
  autoStart: true,  // 文件选择后立即开始上传
  uploadUrl: '/api/upload/chunk',
  wsUrl: 'ws://localhost:3000/ws/file-notification',
  chunkSize: 2 * 1024 * 1024,
  concurrent: 3,
  // 上传完成后获取文件ID
  getFileIdOnComplete: async (file) => {
    // 调用接口获取文件ID
    const response = await fetch(`/api/upload/get-file-id?fileHash=${file.fileHash}`)
    const data = await response.json()
    return data.fileId
  }
})

// 文件状态
const fileStatuses = computed(() => getAllFileStatuses())

// 文件添加处理
function handleFileAdded(file: UploadFile) {
  addFile(file)
  // 自动开始上传
  startFileUpload(file)
}

// 表单提交处理
async function handleSubmit() {
  isSubmitting.value = true
  
  try {
    // 方案1：预上传方案
    const result = await submitFormWithPreUploadedFiles({
      title: formData.value.title,
      description: formData.value.description
    })
    
    if (result.success) {
      alert('表单提交成功！')
      
      // 如果有未完成的文件，提示用户
      if (result.pendingFiles && result.pendingFiles.length > 0) {
        alert(`${result.pendingFiles.length} 个文件正在上传，上传完成后会自动关联`)
      }
    } else {
      alert('表单提交失败，请重试')
    }
  } catch (error) {
    console.error('提交失败:', error)
    alert('提交失败，请重试')
  } finally {
    isSubmitting.value = false
  }
}
</script>
```

### 2. 服务器端接口实现

#### 2.1 表单提交接口

```javascript
// POST /api/form/submit
router.post('/submit', async (req, res) => {
  const { title, description, _pendingFiles, _asyncUpload } = req.body
  
  // 提取文件ID（已完成的文件）
  const fileIds = []
  Object.keys(req.body).forEach(key => {
    if (key.startsWith('file_') && !key.startsWith('file_temp')) {
      fileIds.push(req.body[key])
    }
  })
  
  // 创建表单记录
  const formId = generateFormId()
  const form = {
    id: formId,
    title,
    description,
    fileIds,  // 已完成的文件ID
    pendingFiles: _pendingFiles || [],  // 未完成的文件
    status: _asyncUpload ? 'pending' : 'completed',  // 异步上传标记
    createdAt: Date.now()
  }
  
  // 保存到数据库
  await db.forms.insert(form)
  
  res.json({
    success: true,
    formId,
    message: '表单提交成功'
  })
})
```

#### 2.2 文件关联接口

```javascript
// POST /api/form/associate-file
router.post('/associate-file', async (req, res) => {
  const { formId, tempId, fileId } = req.body
  
  // 查找表单
  const form = await db.forms.findOne({ id: formId })
  if (!form) {
    return res.status(404).json({ error: '表单不存在' })
  }
  
  // 更新文件ID（替换临时ID）
  const fileIds = form.fileIds || []
  const pendingFiles = form.pendingFiles || []
  
  // 移除临时ID，添加文件ID
  const updatedPendingFiles = pendingFiles.filter(f => f.tempId !== tempId)
  fileIds.push(fileId)
  
  // 更新表单
  await db.forms.update(
    { id: formId },
    {
      $set: {
        fileIds: fileIds,
        pendingFiles: updatedPendingFiles,
        // 如果没有待处理的文件了，更新状态
        status: updatedPendingFiles.length === 0 ? 'completed' : 'pending'
      }
    }
  )
  
  res.json({
    success: true,
    message: '文件关联成功'
  })
})
```

#### 2.3 获取文件ID接口

```javascript
// GET /api/upload/get-file-id?fileHash=xxx
router.get('/get-file-id', async (req, res) => {
  const { fileHash } = req.query
  
  // 根据文件Hash查找文件ID
  const file = await db.files.findOne({ fileHash })
  
  if (!file) {
    return res.status(404).json({ error: '文件不存在' })
  }
  
  res.json({
    fileId: file.id,
    fileName: file.fileName,
    fileSize: file.fileSize
  })
})
```

```vue
        </span>
      </span>

  </div>

```

### 2. 提交按钮状态

```vue
<template>
  <button 
    type="submit" 
    :disabled="isSubmitting"
    :class="{ 'has-pending-files': hasPendingFiles }"
  >
    <span v-if="isSubmitting">提交中...</span>
    <span v-else-if="hasPendingFiles">
      提交（{{ pendingFileCount }} 个文件上传中）
    </span>
    <span v-else>提交</span>
  </button>
</template>

<script setup>
const pendingFileCount = computed(() => {
  return fileList.value.filter(f => f.status !== 'success').length
})
</script>
```

```typescript
// 如果用户取消表单，清理未关联的文件
async function cleanupUnassociatedFiles(formId: string) {
  const form = await getForm(formId)
  if (form.status === 'cancelled') {
    // 删除未关联的文件
    for (const fileId of form.pendingFiles) {
      await deleteFile(fileId)
    }
  }
}
```
