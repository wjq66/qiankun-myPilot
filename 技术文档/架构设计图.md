## 🔄 数据流图

### 文件上传数据流

```
用户选择文件
    ↓
File 对象
    ↓
┌─────────────────────────────────────┐
│  Web Worker 处理                     │
│  - 文件切片 (File.slice())          │
│  - 计算文件 Hash (SparkMD5)          │
│  - 计算分片 Hash                     │
└─────────────────────────────────────┘
    ↓
ChunkInfo[] (分片数组)
    ↓
┌─────────────────────────────────────┐
│  IndexedDB 存储                      │
│  - 保存分片 Blob                     │
│  - 保存文件元数据                    │
│  - 保存上传进度                      │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│  请求队列控制                         │
│  - 控制并发数量 (3个)                │
│  - 管理上传顺序                       │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│  上传分片 (并发)                      │
│  POST /api/upload/chunk              │
│  FormData:                           │
│    - file: Blob                      │
│    - chunkIndex: number               │
│    - fileHash: string                 │
│    - chunkHash: string                │
└─────────────────────────────────────┘
    ↓
服务器保存分片
    ↓
┌─────────────────────────────────────┐
│  WebSocket 推送进度                   │
│  { type: 'progress', progress: 50 }  │
└─────────────────────────────────────┘
    ↓
所有分片上传完成
    ↓
┌─────────────────────────────────────┐
│  调用合并接口                         │
│  POST /api/upload/merge              │
│  { fileHash, fileName, totalChunks } │
└─────────────────────────────────────┘
    ↓
服务器合并分片
    ↓
┌─────────────────────────────────────┐
│  WebSocket 推送完成                  │
│  { type: 'mergeComplete' }           │
└─────────────────────────────────────┘
    ↓
清理 IndexedDB
    ↓
上传完成
```

### 断点续传数据流

```
页面刷新/重新打开
    ↓
┌─────────────────────────────────────┐
│  检查 IndexedDB                     │
│  - 查找未完成的文件                 │
│  - 加载文件元数据                    │
└─────────────────────────────────────┘
    ↓
找到未完成的文件
    ↓
┌─────────────────────────────────────┐
│  恢复文件信息                        │
│  - fileHash (文件唯一标识)          │
│  - uploadedChunks (已上传分片)      │
│  - totalChunks (总分片数)           │
└─────────────────────────────────────┘
    ↓
用户点击"继续上传"
    ↓
┌─────────────────────────────────────┐
│  从 IndexedDB 加载分片               │
│  - 加载未上传的分片                  │
│  - 恢复上传状态                      │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│  检查服务器已上传分片                 │
│  GET /api/upload/check?fileHash=xxx  │
└─────────────────────────────────────┘
    ↓
只上传未完成的分片
    ↓
继续上传流程...
```

## 🎯 核心模块职责

### 1. FileUploadTask (核心类)

```
职责：
├── 管理单个文件的上传生命周期
├── 协调各个工具模块
├── 计算和更新上传进度
└── 处理错误和异常情况

关键方法：
├── start()        - 开始上传
├── pause()        - 暂停上传
├── resume()       - 继续上传
├── cancel()       - 取消上传
└── retry()        - 重试上传
```

### 2. chunkWorkerManager (切片管理)

```
职责：
├── 使用 Web Worker 进行文件切片
├── 计算文件 Hash (MD5)
├── 计算分片 Hash
└── 提供进度回调

关键方法：
├── createChunks()           - 创建分片
├── calculateFileHash()      - 计算文件 Hash
└── calculateChunkHashes()    - 计算分片 Hash
```

### 3. indexedDBManager (本地存储)

```
职责：
├── 保存分片数据到 IndexedDB
├── 保存文件元数据
├── 支持断点续传
└── 清理已完成的数据

关键方法：
├── saveChunk()              - 保存分片
├── getChunk()                - 获取分片
├── saveFileMetadata()        - 保存元数据
├── getFileMetadataByHash()  - 根据 Hash 获取元数据
└── deleteChunks()            - 删除分片
```

### 4. websocketManager (实时通信)

```
职责：
├── 管理 WebSocket 连接
├── 接收服务器推送的进度
├── 发送客户端消息
└── 自动重连机制

关键方法：
├── connect()      - 连接 WebSocket
├── send()          - 发送消息
├── onMessage()     - 订阅消息
└── close()         - 关闭连接
```

### 5. requestQueue (请求队列)

```
职责：
├── 控制并发请求数量
├── 管理请求队列
├── 支持优先级
└── 自动重试机制

关键方法：
├── add()           - 添加请求到队列
├── process()       - 处理队列
└── clear()         - 清空队列
```

## 📝 关键数据结构

### UploadFile
```typescript
{
  id: string              // 文件唯一标识
  name: string            // 文件名
  size: number            // 文件大小
  file: File              // 原始文件对象
  status: 'pending' | 'uploading' | 'paused' | 'success' | 'error'
  progress: number        // 上传进度 (0-100)
  speed?: number          // 上传速度 (字节/秒)
  chunkList?: ChunkInfo[] // 分片列表
  uploadedChunks?: number // 已上传分片数
  fileHash?: string       // 文件 Hash
}
```

### ChunkInfo
```typescript
{
  index: number    // 分片索引
  start: number    // 起始位置
  end: number      // 结束位置
  blob: Blob       // 分片数据
  hash?: string    // 分片 Hash
}
```

### FileMetadata
```typescript
{
  fileId: string           // 文件ID
  fileName: string         // 文件名
  fileSize: number         // 文件大小
  fileHash: string         // 文件 Hash
  totalChunks: number      // 总分片数
  uploadedChunks: number[] // 已上传分片索引数组
  createdAt: number        // 创建时间
  updatedAt: number        // 更新时间
}
```
